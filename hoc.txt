CHƯƠNG I: TƯ DUY VÀ QUY TRÌNH DỰNG MÀN HÌNH (SCREEN BUILDING MINDSET)
================================================================================------------------------------------

1.1. TƯ DUY THIẾT KẾ KHAI BÁO (DECLARATIVE UI MINDSET)
   Trong Jetpack Compose, bạn không "xây dựng" màn hình bằng cách kéo thả ô như cũ.
   Bạn dựng màn hình bằng cách mô tả giao diện sẽ trông như thế nào ở từng trạng thái dữ liệu (State):

   [ Dữ Liệu Input (State) ] ──────► [ Hàm @Composable Screen ] ──────► [ Giao diện Màn Hình (UI Pixels) ]

1.2. QUY TRÌNH 4 BƯỚC THẦN THÁNH ĐỂ DỰNG BẤT KỲ MÀN HÌNH NÀO TỪ CON SỐ 0
   Dù là màn hình đơn giản hay phức tạp, hãy luôn tuân theo 4 bước sau:

   ┌──────────────────────────────────────────────────────────────────────────────────────────────────┐
   │ BƯỚC 1: XÁC ĐỊNH BỐ CỤC TỔNG THỂ (CONTAINER)                                                     │
   │         - Màn hình này cuộn được hay không? -> Dùng Column + verticalScroll() hay LazyColumn?    │
   │         - Cần giữ thanh Bottom Bar bên dưới? -> Bọc trong Box hoặc Scaffold.                    │
   │                                                                                                  │
   │ BƯỚC 2: DỰNG TOP BAR / HEADER (THANH TIÊU ĐỀ MÀN HÌNH)                                           │
   │         - Dùng Row(...) để xếp Tiêu đề (Text) và Nút bấm (Button / Icon) nằm ngang.               │
   │         - Thêm statusBarsPadding() để chữ không bị dính vào thanh giờ/pin hệ thống.             │
   │                                                                                                  │
   │ BƯỚC 3: DỰNG NỘI DUNG CHÍNH (CONTENT & CARDS)                                                    │
   │         - Bóc tách nội dung thành các Item Component nhỏ (VD: PostCardItem, GameItem).           │
   │         - Dùng LazyColumn để chứa danh sách item.                                                │
   │                                                                                                  │
   │ BƯỚC 4: THÊM TƯƠNG TÁC VÀ TRẠNG THÁI (INTERACTION & STATE)                                       │
   │         - Xử lý các trạng thái: Loading (Hiện Spinner), Success (Hiện dữ liệu), Error (Hiện lỗi). │
   │         - Mở Dialog / BottomSheet khi bấm nút.                                                  │
   └──────────────────────────────────────────────────────────────────────────────────────────────────┘


================================================================================------------------------------------
CHƯƠNG II: BỘ CÔNG CỤ DỰNG GIAO DIỆN COMPOSE NỀN TẢNG (COMPOSE UI TOOLKIT)
================================================================================------------------------------------

--------------------------------------------------------------------------------------------------------------------
2.1. NẮM VỮNG CHUỖI MODIFIER (MODIFIER CHAIN ORDERING)
--------------------------------------------------------------------------------------------------------------------
Trong Compose, THỨ TỰ viết các hàm trong `Modifier` CỰC KỲ QUAN TRỌNG:

```kotlin
// VÍ DỤ 1: Padding trước Background -> Thêm khoảng trống ngoài (Margin)
Modifier
    .padding(16.dp)
    .background(Color.Blue)

// VÍ DỤ 2: Background trước Padding -> Thêm khoảng trống trong (Padding chuẩn)
Modifier
    .background(Color.Blue)
    .padding(16.dp)

// VÍ DỤ 3: Bo góc -> Đổ màu nền -> Bấm nút (Chuẩn thiết kế Card)
Modifier
    .clip(RoundedCornerShape(12.dp))
    .background(Color.White)
    .clickable { /* Handle click */ }
```

--------------------------------------------------------------------------------------------------------------------
2.2. QUẢN LÝ KHOẢNG CÁCH VÀ CĂN CHỈNH (ARRANGEMENTS & ALIGNMENTS)
--------------------------------------------------------------------------------------------------------------------
1. Căn chỉnh trong `Row` (Chiều ngang):
   - `horizontalArrangement = Arrangement.SpaceBetween`: Đẩy 2 phần tử về 2 mép (Ví dụ: Tiêu đề bên trái, Nút bấm bên phải).
   - `verticalAlignment = Alignment.CenterVertically`: Dóng thẳng hàng các phần tử theo tâm chiều dọc.

2. Căn chỉnh trong `Column` (Chiều dọc):
   - `verticalArrangement = Arrangement.spacedBy(16.dp)`: Tự động tạo khoảng cách 16.dp giữa MỌI phần tử con trong Column (Không cần gõ nhiều Spacer!).

3.1. HƯỚNG DẪN DỰNG MÀN HÌNH CÁ NHÂN TỐI GIẢN (`ProfileScreen.kt`)
--------------------------------------------------------------------------------------------------------------------

Mục tiêu: Màn hình hiển thị thông tin tài khoản dạng chữ tối giản (Minimalist Text Style), kéo sát top màn hình và hỗ trợ đổi Avatar từ bộ nhớ máy.

CODE MẪU VÀ GIẢI THÍCH CHI TIẾT TỪNG DÒNG:

```kotlin
package com.example.playverse.presentation.screen

import android.net.Uri
import androidx.activity.compose.rememberLauncherForActivityResult
import androidx.activity.result.contract.ActivityResultContracts
import androidx.compose.foundation.background
import androidx.compose.foundation.clickable
import androidx.compose.foundation.layout.*
import androidx.compose.foundation.rememberScrollState
import androidx.compose.foundation.shape.CircleShape
import androidx.compose.foundation.verticalScroll
import androidx.compose.material3.*
import androidx.compose.runtime.*
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.clip
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.layout.ContentScale
import androidx.compose.ui.platform.LocalContext
import androidx.compose.ui.text.font.FontWeight
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp
import coil.compose.AsyncImage
import com.example.playverse.data.local.UserPreferences
import com.example.playverse.domain.model.User
import com.example.playverse.presentation.component.common.BottomNavBar

@Composable
fun ProfileScreen(
    modifier: Modifier = Modifier,
    isLoggedIn: Boolean = false,
    user: User? = null,
    onNavigateToLogin: () -> Unit = {},
    onNavigateToRegister: () -> Unit = {},
    onLogoutClick: () -> Unit = {},
    onTabSelected: (String) -> Unit = {},
    onCenterSearchClick: () -> Unit = {}
) {
    val context = LocalContext.current
    val userPreferences = remember(context) { UserPreferences(context) }
    val localUser = remember(user) { user ?: userPreferences.getUser() }

    // Dùng rememberLauncherForActivityResult để mở thư viện ảnh Android
    var selectedImageUri by remember { mutableStateOf<Uri?>(null) }
    val photoPickerLauncher = rememberLauncherForActivityResult(
        contract = ActivityResultContracts.GetContent()
    ) { uri: Uri? ->
        uri?.let {
            selectedImageUri = it
            userPreferences.saveAvatarUri(it.toString()) // Lưu URI vào SharedPreferences
        }
    }

    val displayAvatar = selectedImageUri?.toString() ?: localUser?.avatarUrl

    Box(
        modifier = modifier
            .fillMaxSize()
            .background(Color.White)
    ) {
        Column(
            modifier = Modifier
                .fillMaxSize()
                .statusBarsPadding() // Đẩy sát Top nhưng không bị dính vào Status Bar
                .verticalScroll(rememberScrollState()) // Cho phép cuộn dọc
                .padding(horizontal = 24.dp)
        ) {
            Spacer(modifier = Modifier.height(8.dp))

            // 1. HEADER TITLE
            Text(
                text = "Profile",
                fontSize = 28.sp,
                fontWeight = FontWeight.Bold,
                color = Color(0xFF191C24)
            )

            Spacer(modifier = Modifier.height(20.dp))

            // 2. AVATAR & THÔNG TIN CHÍNH
            Row(
                verticalAlignment = Alignment.CenterVertically,
                modifier = Modifier
                    .fillMaxWidth()
                    .clickable { photoPickerLauncher.launch("image/*") } // Bấm vào để chọn ảnh
            ) {
                if (!displayAvatar.isNullOrEmpty()) {
                    AsyncImage(
                        model = displayAvatar,
                        contentDescription = "Avatar",
                        contentScale = ContentScale.Crop,
                        modifier = Modifier
                            .size(64.dp)
                            .clip(CircleShape)
                    )
                } else {
                    // Nếu chưa có ảnh -> Vẽ ô tròn màu xanh chứa chữ cái đầu tên
                    Box(
                        modifier = Modifier
                            .size(64.dp)
                            .background(Color(0xFF0066FF), shape = CircleShape),
                        contentAlignment = Alignment.Center
                    ) {
                        Text(
                            text = (localUser?.name ?: "P").take(1).uppercase(),
                            color = Color.White,
                            fontWeight = FontWeight.Bold,
                            fontSize = 24.sp
                        )
                    }
                }

                Spacer(modifier = Modifier.width(16.dp))

                Column {
                    Text(
                        text = localUser?.name ?: "Game thủ PlayVerse",
                        fontSize = 18.sp,
                        fontWeight = FontWeight.Bold,
                        color = Color(0xFF191C24)
                    )
                    Text(
                        text = localUser?.email ?: "Chưa cập nhật email",
                        fontSize = 13.sp,
                        color = Color(0xFF64748B)
                    )
                    Text(
                        text = "Đổi ảnh đại diện ✎",
                        fontSize = 12.sp,
                        color = Color(0xFF0066FF),
                        fontWeight = FontWeight.Medium
                    )
                }
            }

            Spacer(modifier = Modifier.height(24.dp))
            HorizontalDivider(color = Color(0xFFF1F5F9))
            Spacer(modifier = Modifier.height(16.dp))

            // 3. DANH SÁCH MỤC CÀI ĐẶT DẠNG CHỮ PHẲNG (TEXT-BASED LIST)
            Text(text = "TÀI KHOẢN", fontSize = 12.sp, fontWeight = FontWeight.Bold, color = Color(0xFF94A3B8))
            Spacer(modifier = Modifier.height(12.dp))

            ProfileTextMenuItem(label = "Thông tin cá nhân", value = localUser?.name ?: "Game thủ")
            ProfileTextMenuItem(label = "Email liên hệ", value = localUser?.email ?: "guest@playverse.com")
            ProfileTextMenuItem(label = "Mã tài khoản (ID)", value = localUser?.id?.take(8) ?: "PV-8892")

            Spacer(modifier = Modifier.height(24.dp))
            Text(text = "HỆ THỐNG", fontSize = 12.sp, fontWeight = FontWeight.Bold, color = Color(0xFF94A3B8))
            Spacer(modifier = Modifier.height(12.dp))

            ProfileTextMenuItem(label = "Cài đặt ứng dụng", value = "Mặc định")
            ProfileTextMenuItem(label = "Trung tâm hỗ trợ", value = "PlayVerse Support")

            Spacer(modifier = Modifier.height(32.dp))

            // 4. NÚT ĐĂNG XUẤT / ĐĂNG NHẬP
            if (isLoggedIn || userPreferences.isLoggedIn()) {
                Button(
                    onClick = onLogoutClick,
                    modifier = Modifier.fillMaxWidth(),
                    colors = ButtonDefaults.buttonColors(containerColor = Color(0xFFEF4444)),
                    shape = RoundedCornerShape(12.dp)
                ) {
                    Text(text = "Đăng Xuất", color = Color.White, fontWeight = FontWeight.Bold)
                }
            } else {
                Row(
                    modifier = Modifier.fillMaxWidth(),
                    horizontalArrangement = Arrangement.spacedBy(12.dp)
                ) {
                    OutlinedButton(
                        onClick = onNavigateToLogin,
                        modifier = Modifier.weight(1f),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Text(text = "Đăng Nhập")
                    }
                    Button(
                        onClick = onNavigateToRegister,
                        modifier = Modifier.weight(1f),
                        colors = ButtonDefaults.buttonColors(containerColor = Color(0xFF0066FF)),
                        shape = RoundedCornerShape(12.dp)
                    ) {
                        Text(text = "Đăng Ký", color = Color.White)
                    }
                }
            }

            Spacer(modifier = Modifier.height(100.dp)) // Tạo khoảng trống để không bị BottomBar che
        }

        // 5. GẮN BOTTOM NAVIGATION BAR Ở ĐÁY MÀN HÌNH
        BottomNavBar(
            modifier = Modifier.align(Alignment.BottomCenter),
            selectedTab = "Profile",
            onTabSelected = onTabSelected,
            onCenterSearchClick = onCenterSearchClick
        )
    }
}

// Component phụ hiển thị dòng thông tin phẳng
@Composable
private fun ProfileTextMenuItem(label: String, value: String) {
    Row(
        modifier = Modifier
            .fillMaxWidth()
            .padding(vertical = 10.dp),
        horizontalArrangement = Arrangement.SpaceBetween,
        verticalAlignment = Alignment.CenterVertically
    ) {
        Text(text = label, fontSize = 15.sp, color = Color(0xFF191C24), fontWeight = FontWeight.Medium)
        Text(text = value, fontSize = 14.sp, color = Color(0xFF64748B))
    }
}
```

1. Dựng Thẻ Bài Viết `PostCardItem`:

   ```kotlin
   @Composable
   fun PostCardItem(post: Post, onLikeClick: () -> Unit) {
       Column(modifier = Modifier.fillMaxWidth()) {
           // Row Tác Giả & Tag Game
           Row(verticalAlignment = Alignment.CenterVertically) {
               // Avatar
               Box(
                   modifier = Modifier
                       .size(38.dp)
                       .background(Color(0xFF0066FF), shape = CircleShape),
                   contentAlignment = Alignment.Center
               ) {
                   Text(text = post.authorName.take(1).uppercase(), color = Color.White, fontWeight = FontWeight.Bold)
               }

               Spacer(modifier = Modifier.width(12.dp))

               Column(modifier = Modifier.weight(1f)) {
                   Text(text = post.authorName, fontSize = 14.sp, fontWeight = FontWeight.Bold)
                   Text(text = post.timeAgo, fontSize = 11.sp, color = Color(0xFF64748B))
               }

               // Badge Tag Tên Game
               Surface(color = Color(0xFF0066FF).copy(alpha = 0.08f), shape = RoundedCornerShape(6.dp)) {
                   Text(text = post.gameTitle, fontSize = 11.sp, color = Color(0xFF0066FF), modifier = Modifier.padding(horizontal = 8.dp, vertical = 3.dp))
               }
           }

           Spacer(modifier = Modifier.height(10.dp))

           // Tiêu đề & Nội dung
           Text(text = post.title, fontSize = 16.sp, fontWeight = FontWeight.Bold, color = Color(0xFF191C24))
           Spacer(modifier = Modifier.height(4.dp))
           Text(text = post.content, fontSize = 14.sp, color = Color(0xFF475569))

           Spacer(modifier = Modifier.height(10.dp))

           // Nút Thả tim & Bình luận
           Row(horizontalArrangement = Arrangement.spacedBy(20.dp)) {
               Row(modifier = Modifier.clickable { onLikeClick() }, verticalAlignment = Alignment.CenterVertically) {
                   Icon(imageVector = Icons.Outlined.FavoriteBorder, contentDescription = "Like", tint = Color(0xFF64748B), modifier = Modifier.size(18.dp))
                   Spacer(modifier = Modifier.width(4.dp))
                   Text(text = "${post.likesCount}", fontSize = 13.sp, color = Color(0xFF64748B))
               }
               Row(verticalAlignment = Alignment.CenterVertically) {
                   Icon(imageVector = Icons.Outlined.ChatBubbleOutline, contentDescription = "Comment", tint = Color(0xFF64748B), modifier = Modifier.size(18.dp))
                   Spacer(modifier = Modifier.width(4.dp))
                   Text(text = "${post.commentsCount}", fontSize = 13.sp, color = Color(0xFF64748B))
               }
           }
       }
   }
   ```

2. Dựng Dialog Đăng Bài Mới `CreatePostDialog`:
   ```kotlin
   @Composable
   fun CreatePostDialog(onDismiss: () -> Unit, onSubmit: (String, String, String) -> Unit) {
       var title by remember { mutableStateOf("") }
       var content by remember { mutableStateOf("") }
       var gameTitle by remember { mutableStateOf("Chung") }

       AlertDialog(
           onDismissRequest = onDismiss,
           confirmButton = {
               Button(onClick = { if (title.isNotBlank() && content.isNotBlank()) onSubmit(title, content, gameTitle) }) {
                   Text("Đăng Bài", color = Color.White)
               }
           },
           dismissButton = { TextButton(onClick = onDismiss) { Text("Hủy") } },
           title = { Text("Tạo Bài Viết Thảo Luận", fontWeight = FontWeight.Bold) },
           text = {
               Column(verticalArrangement = Arrangement.spacedBy(10.dp)) {
                   OutlinedTextField(value = gameTitle, onValueChange = { gameTitle = it }, label = { Text("Tên Game") })
                   OutlinedTextField(value = title, onValueChange = { title = it }, label = { Text("Tiêu đề bài viết") })
                   OutlinedTextField(value = content, onValueChange = { content = it }, label = { Text("Nội dung chia sẻ...") }, minLines = 3)
               }
           }
       )
   }
   ```

CHƯƠNG IV: BÍ QUYẾT LÀM CHỦ LẬP TRÌNH GIAO DIỆN COMPOSE CHUYÊN NGHIỆP
================================================================================------------------------------------

1. Quy tắc chia nhỏ Component (Atomic Design):
   - Đừng viết tất cả UI trong 1 hàm `@Composable` duy nhất dài hàng trăm dòng.
   - Hãy tách thành các hàm nhỏ: `PostCardItem()`, `ProfileTextMenuItem()`, `BottomNavBar()`.

2. Sử dụng Preview để xem trước UI không cần bật máy ảo:
   - Thêm annotation `@Preview` trên hàm Composable để Android Studio tự dựng hình ảnh xem trước tức thì!
   ```kotlin
   @Preview(showBackground = true)
   @Composable
   fun ProfileScreenPreview() {
       PlayVerseTheme { ProfileScreen() }
   }
   ```

3. Luôn bọc giao diện trong Theme chung (`PlayVerseTheme`):
   - Giúp toàn bộ các Text, Button, Card trong ứng dụng tự động đồng bộ phông chữ, màu sắc nền mà bạn không cần phải khai báo lại màu sắc thủ công cho từng ô!
